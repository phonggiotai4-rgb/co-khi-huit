ĐẠI SỐ BOOLE VÀ CÁC CỔNG LOGIC

2.1 CẤU TRÚC ĐẠI SỐ BOOLE

Trang 27 - 28

Cho một tập hợp X hữu hạn. Trong X, người ta trang bị hai toán tử nhị phân là cộng (+) và nhân (⋅).

Các phép toán cộng và nhân kín trong X

∀A, B ∈ X : A + B ∈ X

∀A, B ∈ X : A ⋅ B ∈ X

Các tiên đề của đại số Boole

1- Giao hoán

A + B = B + A

A ⋅ B = B ⋅ A

2- Phối hợp

A + (B + C) = (A + B) + C

A ⋅ (B ⋅ C) = (A ⋅ B) ⋅ C

3- Phân bố

A ⋅ (B + C) = A ⋅ B + A ⋅ C

A + (B ⋅ C) = (A + B) ⋅ (A + C)

4- ∃ hai phần tử trung hòa được ký hiệu là 0 và 1

A + 0 = A

A ⋅ 1 = A

5- ∀ A ∈ X, ∃ phần tử bù của A, được ký hiệu là A

A + A = 1

A ⋅ A = 0

Ghi chú: Ngoài ký hiệu A, còn có thể dùng ký hiệu A' để diễn tả phần tử A bù.

Tập (X, +, ⋅, 0, 1,   ) thỏa 5 tiên đề sẽ hình thành nên cấu trúc đại số Boole.

2.2 CÁC ĐỊNH LÝ

Trang 28 - 29

Định lý 1 (Định lý đối ngẫu)

Một mệnh đề được gọi là đối ngẫu với một mệnh đề khác khi ta thay thế 0 → 1, 1 → 0, + → ⋅, ⋅ → +

Phát biểu định lý: Khi một mệnh đề đúng thì mệnh đề đối ngẫu của nó cũng đúng.

Ví dụ 2.1: Hai mệnh đề sau là đối ngẫu

A + A = 1

A ⋅ A = 0

Định lý 2 (Định lý DeMorgan)

Phát biểu định lý:

Bù của một tổng bằng tích các bù.

Bù của một tích bằng tổng các bù.

A + B = A ⋅ B

A ⋅ B = A + B

Tổng quát

A + B + C + ... = A ⋅ B ⋅ C ...

A ⋅ B ⋅ C ... = A + B + C + ...

Định lý 3

A = A

Định lý 4

A + 1 = 1

A ⋅ 0 = 0

Tổng quát

A + B + C + ... + 1 = 1

A ⋅ B ⋅ C ⋅ ... ⋅ 0 = 0

Định lý 5

A + A = A

A ⋅ A = A

Tổng quát

A + A + A + ... = A

A ⋅ A ⋅ A ⋅ ... = A

Định lý 6 (Định lý hấp thu)

A + (A ⋅ B) = A

A ⋅ (A + B) = A

Ví dụ 2.2: Chứng minh rằng

(A + B)(A + C) = AC + AB

Giải: (A + B)(A + C) = AA + AC + AB + BC

= AC + A B + BC

= AC + A B + BC (A + A)

= AC + A B + ABC + A BC

= (AC + ABC) + (A B + A BC)

= AC + A B

2.3 CÁC PHƯƠNG PHÁP BIỂU DIỄN HÀM BOOLE

Trang 29 - 34

1- Phương pháp đại số

Hàm Boole là một biểu thức được tạo ra bởi các biến Boole (biến nhị phân), hai toán tử nhị phân + (OR) và ⋅ (AND), phép lấy bù (NOT), các dấu ngoặc và dấu bằng.

Với các giá trị cho trước của các biến, hàm Boole có thể có giá trị 0 hay 1.

Ví dụ 2.3: F(A,B,C) = AC + A B

2- Phương pháp bảng chân trị (Truth Table)

Để biểu diễn một hàm Boole bằng bảng chân trị, ta liệt kê một danh sách 2n tổ hợp các 0 và 1 của các biến Boole và một cột chỉ ra giá trị của hàm.

Ví dụ 2.4: Ta có thể biểu diễn hàm F (A,B,C) = AC + A B bằng bảng chân trị như sau

A B C F

3- Phương pháp dạng chuẩn 1

Minterm (tích chuẩn): là tích số của đầy đủ các biến, ở dạng bù hay không bù. Nếu giá trị của biến là 0 thì biến sẽ ở dạng bù, còn nếu giá trị của biến là 1 thì biến sẽ ở dạng không bù.

Với n biến có thể tạo ra 2n minterm.

Minterm được ký hiệu là mi với i là giá trị của tổ hợp nhị phân tạo bởi giá trị các biến.

Ví dụ 2.5: Các minterm cho 3 biến

A B C Biểu thức Ký hiệu
000A B Cm0
001A B Cm1
010A B Cm2
011A B Cm3
100A B Cm4
101A B Cm5
110A B Cm6
111A B Cm7

Dạng chuẩn 1: là dạng tổng các minterm, mà ở đó hàm có giá trị bằng 1.

Tổng quát:

F = ∑i=02n - 1 mi ⋅ Fi

với: mi là minterm thứ i,

Fi là giá trị của hàm F tương ứng với minterm thứ i.

Dạng chuẩn 1 còn được gọi là dạng tổng các tích chuẩn (Standard SOP – Standard Sum-Of-Products). Dạng chuẩn 1 có thể được tạo ra dễ dàng từ dạng tổng các tích (SOP).

Ví dụ 2.6: Hàm F sau được viết ở dạng chuẩn 1

F (A,B,C,D) = A B C D + A B C D + A B C D

Dạng chuẩn 1 có thể có nhiều cách biểu diễn khác nhau.

Ví dụ 2.7: Các cách biểu diễn hàm ở dạng chuẩn 1.

F (A,B,C,D) = A B C D + A B C D + A B C D + A B C D

= 1011 + 1001 + 1110 + 0110

= m11 + m9 + m14 + m6

= ∑ABCD (6, 9, 11, 14)

Bất kỳ một hàm Boole nào cũng có thể biểu diễn ở dạng chuẩn 1

Ví dụ 2.8: Hãy biểu diễn hàm F sau dưới dạng chuẩn 1

F (A,B,C) = AC + A B

Giải: F (A,B,C) = AC + A B

= AC (B+ B) + A B (C+ C)         (áp dụng tiên đề 4 và 5)

= ABC + A B C + A BC + A B C         (áp dụng tiên đề phân bố)

= 111 + 101 + 011 + 010

= m7 + m5 + m3 + m2

= ∑ (2, 3, 5, 7)

Ví dụ 2.9: Hãy biểu diễn hàm sau dưới dạng chuẩn 1

F (A,B,C) = (A + B) (A + C)

Giải: F (A,B,C) = (A + B) (A + C)

= A A + AC + A B + B C

= AC (B + B) + A B (C + C) + B C (A + A)

= ABC + A B C + A B C + A B C + A B C + A B C

= ABC + A B C + A B C + A B C         (áp dụng định lý 5)

= 111 + 101 + 001 + 000

= m7 + m5 + m1 + m0

= ∑ (0, 1, 5, 7)

Ví dụ 2.10: Hãy viết dạng biểu thức của hàm F(A,B,C) = ∑ (1, 4, 5, 6)

Giải: F(A,B,C) = ∑ (1, 4, 5, 6)

= 001 + 100 + 101 + 110

= A B C + A B C + A B C + AB C

Ví dụ 2.11: Hãy viết dạng biểu thức của hàm F(A,B,C,D) = ∑ (1, 4, 5, 6)

Giải: F(A,B,C,D) = ∑ (1, 4, 5, 6)

= 0001 + 0100 + 0101 + 0110

= A B C D + A B C D + A B C D + A BC D

4- Phương pháp dạng chuẩn 2

Maxterm (tổng chuẩn): là tổng số của đầy đủ các biến, ở dạng bù hay không bù. Nếu giá trị của biến là 1 thì biến sẽ ở dạng bù, còn nếu giá trị của biến là 0 thì biến sẽ ở dạng không bù.

Với n biến có thể tạo ra 2n maxterm.

Maxterm được ký hiệu là Mi với i là giá trị của tổ hợp nhị phân tạo bởi giá trị các biến.

Ví dụ 2.12: Các maxterm cho 3 biến

A B C Biểu thức Ký hiệu
000A + B + CM0
001A + B + CM1
010A + B + CM2
011A + B + CM3
100A + B + CM4
101A + B + CM5
110A + B + CM6
111A + B + CM7

Dạng chuẩn 2: là dạng tích các maxterm, mà ở đó hàm có giá trị bằng 0.

Tổng quát:

F = ∏i=02n - 1 (Mi + Fi)

với: Mi là maxterm thứ i,

Fi là giá trị của hàm F tương ứng với maxterm thứ i.

Dạng chuẩn 2 còn được gọi là dạng tích các tổng chuẩn (Standard POS – Standard Product-Of-Sums). Dạng chuẩn 2 có thể được tạo ra dễ dàng từ dạng tích các tổng (POS).

Ví dụ 2.13: Hàm F sau được viết ở dạng chuẩn 2

F (A,B,C,D) = (A + B + C + D)(A + B + C + D)(A + B + C + D)(A + B + C + D)

Dạng chuẩn 2 có thể có nhiều cách biểu diễn khác nhau.

Ví dụ 2.14: Các cách biểu diễn hàm ở dạng chuẩn 2.

F (A,B,C,D) = (A + B + C + D)(A + B + C + D)(A + B + C + D)(A + B + C + D)

= 1001 ⋅ 0011 ⋅ 1110 ⋅ 0110

= M9 ⋅ M3 ⋅ M14 ⋅ M6

= ∏ABCD (3, 6, 9, 14)

Bất kỳ một hàm Boole nào cũng có thể biểu diễn ở dạng chuẩn 2

Ví dụ 2.15: Hãy biểu diễn hàm F sau dưới dạng chuẩn 2

F (A,B,C) = (A + B)(A + C)

Giải: F (A,B,C) = (A + B)(A + C)

= (A + B + CC)(A + BB + C)         (áp dụng tiên đề 4 và 5)

= (A + B + C)(A + B + C)(A + B + C)(A + B + C)         (tiên đề phân bố)

= 010 ⋅ 011 ⋅ 100 ⋅ 110

= M2 ⋅ M3 ⋅ M4 ⋅ M6

= ∏ (2, 3, 4, 6)

Ví dụ 2.16: Hãy biểu diễn hàm F sau dưới dạng chuẩn 2

F (A,B,C) = AC + A B

Giải: F (A,B,C) = AC + A B

= (A + A)(A + B)(A + C)(B + C)

= (A + B)(A + C)(B + C)

= (A + B + CC)(A + C + BB)(B + C + AA)

= (A + B + C)(A + B + C)(A + B + C)(A + B + C)(A + B + C)(A + B + C)

= (A + B + C)(A + B + C)(A + B + C)(A + B + C)

= 000 ⋅ 001 ⋅ 100 ⋅ 110

= M0 ⋅ M1 ⋅ M4 ⋅ M6

= ∏ (0, 1, 4, 6)

Ví dụ 2.17: Hãy viết dạng biểu thức của hàm F (A,B,C) = ∏ (0, 2, 3 ,7)

Giải: F (A,B,C) = ∏ (0, 2, 3 ,7)

= 000 ⋅ 010 ⋅ 011 ⋅ 111

= (A + B + C) (A + B + C)(A + B + C)(A + B + C)

Ví dụ 2.18: Hãy viết dạng biểu thức của hàm F (A,B,C,D) = ∏ (0, 2, 3 ,7)

Giải: F (A,B,C,D) = ∏ (0, 2, 3 ,7)

= 0000 ⋅ 0010 ⋅ 0011 ⋅ 0111

= (A + B + C + D)(A + B + C + D) (A + B + C + D)(A + B + C + D)

Nhận xét:

1- Bù của minterm là maxterm và ngược lại

mi = Mi ⇔ Mi = mi

2- Chuyển đổi giữa hai dạng chuẩn

Ví dụ 2.19: Hãy đổi hàm F sau thành dạng chuẩn 2

F (A,B,C) = ∑ (0, 2, 3, 7)

Giải: F (A,B,C) = ∑ (1, 4, 5, 6) = m1 + m4 + m5 + m6

F (A,B,C) = F (A,B,C) = m1 + m4 + m5 + m6 = m1 ⋅ m4 ⋅ m5 ⋅ m6

= M1 ⋅ M4 ⋅ M5 ⋅ M6 = ∏ (1, 4, 5, 6)

2.5 TRƯỜNG HỢP TÙY ĐỊNH

Trang 37

Trong thực tế có những trường hợp một vài tổ hợp nhị phân của các biến là không xảy ra. Do đó, giá trị của hàm tương ứng với những tổ hợp nhị phân này có thể là 0 hay 1 đều được, người ta gọi đó là những trường hợp tùy định (don't care, viết tắt là d). Khi điền vào bảng chân trị những trường hợp tùy định, ta dùng ký hiệu X.
