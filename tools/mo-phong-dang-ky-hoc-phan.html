Hướng dẫn sử dụng HUIT Scheduler

1. Nhập File Excel thời khóa biểu

Nhấn "Tải lịch (.xls)" để chọn file Excel thời khóa biểu từ cổng sinh viên HUIT (`.xls` hoặc `.xlsx`). Hệ thống sẽ tự đọc mã LHP, số TC, tiết học và phòng học.

2. Bảng Giá Tín Chỉ Theo Khóa

Hỗ trợ đầy đủ đơn giá cho các Khóa: K14, K15, K16, K26. Bạn có thể thay đổi Khóa trong bảng Dự Toán Học Phí để tự tính toán học phí dự kiến.
